# 💰 Gerenciador de Contas (Python + SQLite)

Projeto desenvolvido em Python para gestão de contas a pagar/receber, utilizando a biblioteca nativa **SQLite** para persistência de dados.

## 📌 Funcionalidades
- [x] Conexão com banco de dados SQLite (`minhas_contas.db`)
- [x] Criação automática da tabela de contas
- [x] Listagem de contas com cálculo de valor total acumulado
- [ ] Inserção de novas contas *(em desenvolvimento)*

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **SQLite3**
- **Git & GitHub** (Controle de versão)

## 📂 Estrutura do Projeto
- `app.py`: Código principal com a lógica da aplicação e funções do banco de dados.
- `minhas_contas.db`: Arquivo do banco de dados local.
